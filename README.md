# WB Seller Audit

Инструмент для восстановления истории продаж продавца Wildberries/MPStats и предварительного налогового аудита.

MVP:

- Chrome Extension (Manifest V3) перехватывает JSON/XHR/fetch на MPStats и умеет экспортировать сырые данные.
- Backend на FastAPI нормализует продажи, считает накопительный доход, помесячные обороты и rolling-окна.
- DeepSeek используется только для классификации SKU/товаров; налоговая математика остается детерминированной.
- Все выводы являются предварительным аудитом и требуют сверки с официальными отчетами WB/Ozon и документами ФНС.
